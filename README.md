# სამედიცინო ბარათი — legal pages

The privacy policy and the terms of use for the app, published with GitHub Pages. The app's
About screen and the Play Console both point at these exact addresses:

- https://sabatsibadze1.github.io/samedicino-barati-legal/privacy/
- https://sabatsibadze1.github.io/samedicino-barati-legal/terms/

Copy this whole folder into a public repository named `samedicino-barati-legal` under the same
GitHub account. The workflow in `.github/workflows/pages.yml` switches Pages on and publishes on
every push to `main`. Nothing here is generated: edit the HTML, push, and the page updates.

The text is a draft written from what the app actually does. Counsel must review it before the
release. The contact address is the owner's inbox for now.
